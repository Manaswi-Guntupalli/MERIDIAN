## Refreshing a screenshot

1. Capture in landscape at a clean desktop resolution, ideally with the Meridian sidebar visible.
2. Remove browser chrome, operating-system overlays, and sensitive production data before committing.
3. Replace the correctly named image in `docs/screenshots/meridian/`.
4. Keep the screenshot focused on one claim: an action, an explanation, or the proof behind it.
5. Check the root README locally or in the pull request preview before merging.

The README intentionally uses a curated subset of these assets. The remaining screenshots are preserved here for demo documentation, future release notes, and alternate visual layouts.
